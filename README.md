# Site Arba Solar

Este é o site oficial da Arba Solar, uma empresa especializada em instalações de placas solares. O site foi desenvolvido com tecnologias modernas e é totalmente responsivo.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome (para ícones)

## Características

- Design moderno e responsivo
- Navegação suave
- Animações em scroll
- Formulário de contato
- Menu mobile
- Seções informativas sobre serviços e benefícios
- Integração com redes sociais

## Como Usar

1. Clone este repositório:
```bash
git clone https://github.com/seu-usuario/arba-solar.git
```

2. Navegue até o diretório do projeto:
```bash
cd arba-solar
```

3. Abra o arquivo `index.html` em seu navegador ou use um servidor local.

## Estrutura do Projeto

```
arba-solar/
├── index.html
├── styles.css
├── script.js
└── README.md
```

## Personalização

Para personalizar o site, você pode:

1. Alterar as cores no arquivo `styles.css` (variáveis CSS no início do arquivo)
2. Modificar o conteúdo no arquivo `index.html`
3. Ajustar as animações no arquivo `script.js`
